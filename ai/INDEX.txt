DOCUMENTATION INDEX — keen_web_multiselect (Phoenix LiveView wrapper)
=====================================================================

LLM-oriented reference for `keen_web_multiselect`, the Elixir/Phoenix wrapper
around the `@keenmate/web-multiselect` custom element. This folder documents the
WRAPPER surface (HEEx component, LiveView hook, helpers). For the underlying web
component's own API, see the upstream package's `ai/` folder and
https://github.com/keenmate/web-multiselect.

CRITICAL FACTS
--------------
- The component is `<.web_multiselect>`, a Phoenix function component. It renders
  the `<web-multiselect>` custom element. No GenServer, no process state.
- The SAME call works in a dead view (plain HEEx) and a LiveView. LiveView event
  wiring is OPT-IN via `hook={true}`.
- snake_case HEEx attrs map to kebab-case element attributes
  (`search_placeholder` -> `search-placeholder`).
- Bundled assets: no `npm install`. The upstream JS+CSS ship in the Hex package's
  `priv/static/`. Wire them with the installer, an esbuild import, or Plug.Static.
- Import the component with: `import Keenmate.WebMultiselect.Components`

JS hook: KeenWebMultiselectHook (in priv/static/keen_web_multiselect_hook.js)
Server->client event listened for: "web_multiselect:update"
Client->server events emitted:     "web_multiselect:select" | ":deselect" | ":change"
